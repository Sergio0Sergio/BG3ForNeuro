# CONTEXT.md

## Glossary

- **option_index** — номер варианта ответа в диалоге; равен порядку кнопки в окне диалога игры (1-based). Канонический идентификатор, который Neuro видит в состоянии и по которому мод совершает выбор.
- **option_text** — текст варианта ответа; служит подстраховкой при выборе, если нумерация окна и состояние разошлись.
- **Выбор варианта диалога** (dialogue option selection) — действие «Neuro выбрала вариант → вариант реально выбран в игре». Выполняется только на клиентском контексте; серверного пути нет.
- **Серверный контекст** (server context) — основная половинка мода: эмиссия состояния игры и приём команд от приложения.
- **Клиентский контекст** (client context) — вторая половинка мода, работает в контексте клиента игры и видит интерфейс; единственный способ реально кликнуть по UI (в т.ч. по диалогу).
- **Cross-OS сообщение** — передача команды «выбери вариант» с серверного контекста на клиентский. В одиночной игре — внутри одного процесса; в мультиплеере — по сети.
- **Честный отказ** (X1) — принцип: если выбрать вариант невозможно (клиент недоступен, диалог закрылся), мод явно отвечает `not_supported`+предупреждением, а не молчит, чтобы Neuro не оставалась без канала обратной связи.
